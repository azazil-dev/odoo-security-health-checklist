Security Healthcheck

Odoo 17 CE & EE 43 Automated Checks Audit PDF Report 100% Safe & Read-Only

One-click, safe and comprehensive security assessment for your Odoo instance. Get a score from 0 to 100, a grade from A to F, plain-language findings with direct remediation links, and an executive PDF audit report. Strictly read-only: never alters settings, never guesses passwords, and never makes outbound internet calls.

1
Healthcheck Overview & Live Scoring Dashboard

Security Healthcheck → History → select scan record (Overall score, grade badge, area breakdown with progress bars, and severity counters).

2
App Menu Structure

Quick access to Run Healthcheck wizard, History, Checks configuration, Accepted risks, and Settings.

3
Detailed Findings & Direct Record Links

Clear explanations, remediation steps, and instant "Open records" buttons to view affected users, actions, or parameters directly.

Where to Find It (Menu Locations)

1. Run Healthcheck
Security Healthcheck → Run healthcheck

Launches instant read-only audit wizard and immediately redirects to results.

2. Audit History & Trends
Security Healthcheck → History

Track score progression over time with list, line chart, and delta vs. previous scans.

3. Configuration & Settings
Security Healthcheck → Configuration

Enable/disable individual checks, review accepted risks, and set retention policies.

1. Access & Authentication

Admin 2FA enforcement, default administrator logins, dormant accounts, weak password policies, and open public signup scopes.

2. Server Configuration

Database manager exposure (list_db), master password hashing, HTTPS enforcement, unencrypted SMTP, and Odoo/Python support cycles.

3. Data & Demo Content

Demo data leftovers in production, sensitive public attachments, global ACL rules open to everyone, and missing record rules.

4. API Keys & Integrations

Stale API keys (>180 days), keys without expiration, keys owned by inactive or administrator accounts, and external webhooks.

5. Custom Code & Automation

Server actions with raw Python, automated actions, crons running as admin, and static code scanning for risky execution patterns.

6. Platform & Health

Pending module upgrades, broken module states, failing cron jobs, failed outgoing email queues, and filestore storage modes.

Scoring Methodology & Grade Bands

Penalty Weights by Severity
  • Critical Weight 10 • Core vulnerability / direct compromise risk
  • High Weight 6 • Significant security risk
  • Medium Weight 3 • Security best-practice violation
  • Low Weight 1 • Minor hygiene or hardening advisory
  • Info Weight 0 • Informational telemetry (no penalty)
Grade Scale & Rules
A: 90–100 B: 80–89 C: 70–79 D: 60–69 E: 50–59 F: < 50

Critical Cap: If any Critical check fails, the overall grade is automatically capped at C (or worse) to prevent high-risk instances from displaying false reassurance.

Safe by Design: Non-Intrusive & Air-Gapped

Security Healthcheck is strictly read-only with respect to your Odoo configuration and database records. It never attempts password brute-forcing or credential validation, never executes scanned Python code strings, and never makes outbound network requests to third-party servers. All secrets (passwords, tokens, API key values) are strictly excluded from results and reports.
